# Структура тестового модуля YaXUnit

Тестовый общий модуль содержит предопределённую экспортную процедуру `ИсполняемыеСценарии`, которая декларативно настраивает модуль `ЮТТесты`. Каждый зарегистрированный тестовый метод также должен быть экспортным.

### Минимальный каркас

```bsl
Процедура ИсполняемыеСценарии() Экспорт
    ЮТТесты
        .ДобавитьТестовыйНабор("Расчет суммы")
            .ДобавитьТест("СкладываетДваЧисла");
КонецПроцедуры

Процедура СкладываетДваЧисла() Экспорт
    Результат = 2 + 3;
    ЮТест.ОжидаетЧто(Результат).Равно(5);
КонецПроцедуры
```

### Практика

- Один тест проверяет один наблюдаемый результат.
- Имя теста описывает поведение, а не внутреннюю реализацию.
- Подготовку данных выносите в локальные функции или обработчики `Перед`/`После`, если она повторяется.
- Не вызывайте тестовые методы друг из друга: общую логику вынесите в отдельный помощник.

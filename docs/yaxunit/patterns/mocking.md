# Мокирование зависимостей с Мокито

Мокируйте границу зависимости, а не внутренние шаги проверяемого алгоритма. Цикл состоит из обучения, перехода в прогон и проверки вызовов.

### Базовый цикл

```bsl
Мокито.Обучение(Провайдер)
    .Когда("ПолучитьКурс", Новый Массив)
    .Вернуть(90);

Мокито.Прогон();

Результат = Сервис.Пересчитать(Провайдер);

Мокито.Проверить(Провайдер)
    .КоличествоВызовов("ПолучитьКурс")
    .Равно(1);
ЮТест.ОжидаетЧто(Результат).Равно(90);
```

Методы платформы напрямую не перехватываются. Если такая подмена необходима, изолируйте платформенный вызов собственной экспортной обёрткой и мокируйте её. После теста сбрасывайте состояние через `Мокито.Сбросить()`, если это не делает окружение запуска.

# Регистрация и параметризация тестов YaXUnit

Регистрацию стройте fluent-цепочкой от `ЮТТесты`. Клиентские и серверные сценарии лучше задавать явными методами, чтобы контекст выполнения читался из теста.

### Параметризованный тест

```bsl
Процедура ИсполняемыеСценарии() Экспорт
    ЮТТесты
        .ДобавитьТестовыйНабор("Сложение", "unit")
            .ДобавитьТест("СуммаСоответствуетОжиданию")
                .СПараметрами(1, 2, 3)
                .СПараметрами(-1, 1, 0)
                .Тег("быстрый");
КонецПроцедуры

Процедура СуммаСоответствуетОжиданию(Первое, Второе, Ожидаемое) Экспорт
    ЮТест.ОжидаетЧто(Первое + Второе).Равно(Ожидаемое);
КонецПроцедуры
```

### Выбор регистрации

- `ДобавитьТест` — доступные контексты тестового модуля.
- `ДобавитьКлиентскийТест` — только клиент.
- `ДобавитьСерверныйТест` — только сервер.
- `ДобавитьТестовыйНабор` — общие теги и настройки группы.
- `Перед` и `После` — обработчики конкретного теста или текущей группы.

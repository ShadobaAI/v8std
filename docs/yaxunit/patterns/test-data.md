# Создание тестовых данных YaXUnit

Получайте API тестовых данных через `ЮТест.Данные()`. Для `СоздатьЭлемент` и `СоздатьДокумент` первым аргументом обязательно передаётся менеджер объекта метаданных.

### Короткое создание документа

```bsl
Реквизиты = Новый Структура;
Реквизиты.Вставить("Дата", ТекущаяДата());
Реквизиты.Вставить("Комментарий", ЮТест.Данные().СлучайнаяСтрока());

ДокументСсылка = ЮТест.Данные().СоздатьДокумент(
    Документы.ЗаказКлиента,
    Реквизиты);
```

### Конструктор объекта

```bsl
ДокументСсылка = ЮТест.Данные()
    .КонструкторОбъекта(Документы.ЗаказКлиента)
    .Установить("Дата", ТекущаяДата())
    .ФикцияОбязательныхПолей()
    .Записать();
```

Явно задавайте значения, значимые для проверяемого поведения. Фиктивные и случайные значения используйте только для несущественных обязательных полей.

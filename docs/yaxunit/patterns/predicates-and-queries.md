# Предикаты и запросы в тестах YaXUnit

Предикат описывает условие один раз и может использоваться при проверке коллекции, настройке мока или специализированном assertion состояния базы.

### Проверка записей базы

```bsl
Условие = ЮТест.Предикат()
    .Реквизит("Проведен").Равно(Истина)
    .Реквизит("СуммаДокумента").Больше(0);

ЮТест.ОжидаетЧтоТаблицаБазы("Документ.ЗаказКлиента")
    .СодержитЗаписи(Условие);
```

Для presence, absence, count, fields или row sets предпочитайте `ОжидаетЧтоТаблицаБазы(...)` и `ЮТУтвержденияИБ`, а не `ЮТЗапросы.Записи(...)` с общей проверкой коллекции. Используйте `ЮТЗапросы` для получения данных как входа теста либо когда результат запроса является проверяемым поведением и специализированный assertion не подходит.

После `Реквизит` или `Свойство` последующие условия относятся к выбранному значению. При сложном условии проверяйте, на каком реквизите находится текущий контекст fluent-цепочки.

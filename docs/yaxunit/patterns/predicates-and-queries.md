# Предикаты и запросы в тестах YaXUnit

Предикат описывает условие один раз и может использоваться при проверке коллекции, настройке мока или поиске записей информационной базы.

### Поиск записей

```bsl
Условие = ЮТест.Предикат()
    .Реквизит("Проведен").Равно(Истина)
    .Реквизит("СуммаДокумента").Больше(0);

Записи = ЮТЗапросы.Записи("Документ.ЗаказКлиента", Условие);
ЮТест.ОжидаетЧто(Записи).ИмеетДлинуБольше(0);
```

После `Реквизит` или `Свойство` последующие условия относятся к выбранному значению. При сложном условии проверяйте, на каком реквизите находится текущий контекст fluent-цепочки.

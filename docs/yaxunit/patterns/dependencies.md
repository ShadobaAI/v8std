# Зависимости тестов YaXUnit

Зависимости используйте для тяжёлых ресурсов, которые нужно подготовить один раз и переиспользовать, особенно когда клиентские файлы требуются серверному тесту.

### Файлы проекта

```bsl
Функция ИсполняемыеСценарии() Экспорт
    Возврат ЮТТесты
        .ДобавитьСерверныйТест("ПроверяетШаблон")
        .ЗависитОт()
        .ФайлыПроекта("fixtures/template.json");
КонецФункции

Процедура ПроверяетШаблон() Экспорт
    Описание = ЮТЗависимости.ФайлыПроекта("fixtures/template.json");
    ПолноеИмя = ЮТест.Зависимость(Описание).ПолноеИмя;
    ЮТест.ОжидаетЧто(ЮТФайлы.Существует(ПолноеИмя)).ЭтоИстина();
КонецПроцедуры
```

Если зависимость не разрешена, связанный тест пропускается. Обычную быструю подготовку данных оставляйте в обработчиках `Перед` или локальных помощниках.

# Изоляция и очистка тестовых данных YaXUnit

Для изолированного теста выбирайте один основной механизм очистки. Транзакция подходит, когда проверяемый код может полностью выполняться внутри неё; автоматическое удаление — когда транзакция неприменима.

### Транзакционный тест

```bsl
Возврат ЮТТесты
    .ДобавитьТест("ПроведениеФормируетДвижения")
    .ВТранзакции();
```

### Автоматическое удаление

```bsl
Возврат ЮТТесты
    .ДобавитьТест("ОбменСоздаетДокумент")
    .УдалениеТестовыхДанных();
```

Автоматически отслеживаются данные, созданные API `ЮТест.Данные()`. Механизм удаления удаляет созданные объекты, но не откатывает произвольные изменения уже существующих данных — такие изменения тест должен восстановить явно.

## ЮТест.Контекст

`Функция ЮТест.Контекст() Экспорт`

Умный контекст, в который можно сохранять и получать из него промежуточные данные
Этот контекст работает с см. КонтекстТеста, см. КонтекстТестовогоНабора и см. КонтекстМодуля.
При получении значения выполняется поиск во всех 3 контекста поочереди.
При установке значения, оно устанавливается в текущий контекст, например, в событии перед тестовым наборов в м. КонтекстТестовогоНабора

## ЮТест.Упал

`Процедура ЮТест.Упал(СообщениеОбОшибке = "Тест явно завершен с ошибкой", ФактическоеЗначение = Неопределено, ОжидаемоеЗначение = Неопределено) Экспорт`

Вызывает явное падение теста.

Используется для явного указания, что тест должен упасть в определенной точке выполнения.
Поддерживает несколько режимов работы:
- С фактическим и ожидаемым значениями - регистрирует ошибку сравнения
- Только с фактическим значением - регистрирует ошибку утверждения
- Без значений или только с сообщением - регистрирует простую ошибку утверждения

**Параметры:**
- `СообщениеОбОшибке` — Строка, Неопределено — Описание ошибки
- `ФактическоеЗначение` — Произвольный, Неопределено — Фактическое значение для сравнения (необязательный)
- `ОжидаемоеЗначение` — Произвольный, Неопределено — Ожидаемое значение для сравнения (необязательный)

Источник ядра: `exts/yaxunit/src/CommonModules/ЮТест/Module.bsl:135`.

**Возвращает:**

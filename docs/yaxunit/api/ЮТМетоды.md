## ЮТМетоды.ВызватьМетодМодуля

`Процедура ЮТМетоды.ВызватьМетодМодуля(ИмяМодуля, ИмяМетода, Параметры = Неопределено) Экспорт`

Выполняет вызов метода модуля конфигурации

Ограничения:
- Метод недоступен в веб-клиенте
- Модуль должен существовать в конфигурации
- Метод должен быть экспортируемым

**Параметры:**
- `ИмяМодуля` — Строка — Имя модуля
- `ИмяМетода` — Строка — Имя метода
- `Параметры` — Неопределено — Вызов метода без параметров - Массив из Произвольный - Параметры вызова метода В качестве конструктора параметров можно использовать см. МассивПараметров

# VanessaExt и VAExtension: зависимости функций, парсер, запись и дымовые тесты

Справочная переработка текстов MainHelp 1.2.043.1, глава 02. Названия JSON-полей и элементы, видимые только на изображениях уроков, здесь не восстановлены. Рекомендации источника относятся к этой редакции и не определяют фактические настройки другого релиза.

## Различить компоненту и расширение клиентской базы

VanessaExt — внешняя компонента, включаемая отдельным флагом. Справка рекомендует включение при первом запуске: компонента ускоряет Vanessa и добавляет работу с окнами ОС, скриншотами и звуком. Она также поддерживает значительную часть интерактивной справки.

VAExtension — расширение, установленное в базе клиента тестирования. Оно требуется для механизма защиты редактируемого текста от затирания после серверного вызова и рекомендованной передачи данных макета. Одно название не является альтернативным написанием другого.

Источники: [урок 29][s29], [урок 80][s80], [урок 21][s21], [урок 20][s20].

## Выбрать парсер и поиск файлов

Флаг парсера переключает старый встроенный парсер feature на новый парсер VanessaExt; новый рекомендован как более быстрый. Использование компоненты при поиске файлов немного ускоряет поиск и действует только в Windows.

Для неудачной тихой установки существует отдельный режим завершения сеанса с кодом возврата 4. Это условный эффект включённой опции, а не универсальный код любой ошибки Vanessa.

Источники: [урок 29][s29].

## Настроить запись действий по устойчивым идентификаторам

При включённом предпочтении имён генератор записи выбирает шаг по имени элемента вместо заголовка, когда есть выбор; этот режим рекомендован как более надёжный. При отключённом предпочтении заголовок всё же не гарантирован: неодинаковые элементы с одинаковым заголовком могут потребовать имя.

Ctrl+R начинает запись; если TestClient ещё не подключён, сначала подключается текущая строка таблицы. Повторное Ctrl+R останавливает запись при активном менеджере. Всплывающее окно остановки требует VanessaExt и рекомендовано для быстрого завершения. Полученный текст вставляется в позицию курсора редактора, поэтому место вставки существенно.

Источники: [урок 31][s31], [урок 67][s67].

## Проверить зависимость нужной операции

Эмуляция клавиатурного ввода требует VanessaExt. Поиск картинок с компонентой имеет числовую настройку добротности; выключение переключает на устаревший SikuliX, а справка рекомендует компоненту. Скриншоты VanessaExt и скриншоты внешней утилитой выбираются разными режимами. Дополнительные процессы с масками для снимков поддерживаются именно режимом компоненты.

Механизм защиты ввода меняет свойство «ОбновлениеТекстаРедактирования» после «Тогда открылось окно» и требует VAExtension. Паузы через ping предназначены для случая без VanessaExt.

Источники: [урок 12][s12], [урок 10][s10], [урок 51][s51], [урок 21][s21], [урок 20][s20].

## Сгенерировать дымовые feature с нужным составом

Настройки дымовых тестов задают язык, выходной каталог feature, каталог текстовых списков объектов-исключений и файл настройки сценариев. Опция очистки перед генерацией удаляет все существующие feature в выходном каталоге.

Отдельные фильтры включают в расширенные действия либо итоговые feature только объекты с хотя бы одним не помеченным на удаление элементом текущей базы. Есть имя конфигурации поставщика для сравнения конфигураций. Эти параметры влияют на состав генерируемых тестов; полнота результата зависит от данных базы и исключений. Команда генератора дымовых тестов доступна среди инструментов редактора.

Источники: [урок 30][s30], [урок 72][s72].

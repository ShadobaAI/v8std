# Настройки Vanessa: сохранение JSON, каталоги, язык и перенос сеанса

Справочная переработка текстов MainHelp 1.2.043.1, глава 02. Названия JSON-полей и элементы, видимые только на изображениях уроков, здесь не восстановлены. Рекомендации источника относятся к этой редакции и не определяют фактические настройки другого релиза.

## Сохранить настройки и перенести их в другой сеанс

Изменение значения в форме само по себе не сохраняет настройку при закрытии Vanessa. Команда сохранения текущих настроек делает это явно. Выгрузка в JSON подходит для передачи настроек и запуска в CI; обратная команда загружает JSON. Важная особенность загрузки: отсутствующая в файле настройка получает значение по умолчанию, а не сохраняет прежнее значение сеанса. Сравнение текущих настроек с файлом помогает найти расхождение двух сеансов.

Список клиентов имеет отдельное сохранение в настройках текущего пользователя текущей базы. Обычное сохранение пользовательских настроек Vanessa его не сохраняет. При выгрузке общих настроек в JSON список клиентов включить можно; пример файла для отдельной загрузки списка получают сохранением настроек в файл.

Источники: [урок 74][s74], [урок 81][s81], [урок 1][s1].

## Настроить рабочие каталоги и шаблон feature

Каталог проекта содержит файлы, к которым обращаются сценарии; руководство рекомендует всегда его указывать. Каталог инструментов — место обработки Vanessa Automation или Vanessa Automation Single. Для шаблона нового feature включается соответствующая опция и указывается файл шаблона.

Отдельный каталог временных файлов полезен, когда ОС запрещает запуск BAT из пользовательского временного каталога. При пустой настройке используется временный каталог пользователя; при заполненной там создаются временные файлы скриптов.

Источники: [урок 35][s35].

## Выбрать язык и совместимость синтаксиса

Язык feature выбирается в настройке языка, если сценарии создаются и запускаются не на текущем языке. Опция автоматического применения служебного тега tree избавляет от его объявления в каждом файле: руководство рекомендует иерархию шагов и включённый флаг. Историческое назначение тега — обозначать такую иерархию.

Вычисление выражений в фигурных скобках без секции «Переменные» включается отдельной опцией по необходимости. Эти сведения описывают режимы, а не JSON-имена настроек.

Источники: [урок 38][s38], [урок 36][s36].

## Восстановить настройки после перемещения библиотек

После переноса обработки или библиотек полезен сброс кэша прочитанных шагов. Это отдельная команда от полного возврата всех настроек к значениям по умолчанию. Настройка открытия последнего feature может сразу загрузить и выполнить файл предыдущей сессии; её следует учитывать при разборе неожиданного запуска. Здесь же задаются вопрос при закрытии формы, редкий путь общих настроек выполнения и внешний редактор feature.

Источники: [урок 34][s34], [урок 33][s33].

## Найти встроенный урок и команду запуска

Список уроков доступен с панели и начальной страницы; урок запускается ссылкой «Запустить урок». При включённом поиске уроков по элементу формы сочетание Alt+H находит уроки для элемента под курсором. Справка предлагает интерактивный урок, видео, PDF или Markdown. Кэш справки имеет отдельный каталог; если он не задан, каталог создаётся рядом с обработкой. Генерация отсутствующей озвучки использует текущие настройки речи. Есть опции закрытия выполненного урока, показа помощника первого запуска и повторного вызова помощника.

На странице «Прочее» можно вычислить PID менеджера и получить команду ОС для запуска сессии, в том числе с сообщениями в консоль. В справке консольный вариант рекомендован для снижения нагрузки на диск; точная строка генерируется текущей Vanessa.

Источники: [урок 28][s28], [урок 57][s57], [урок 50][s50].

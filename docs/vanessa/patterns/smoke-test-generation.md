# Генератор дымовых тестов: формы, исключения и данные

## Назначение и границы

Генератор формирует `.feature` по типам и объектам метаданных. Проверки открытия списка/объекта отличаются от записи, копирования, ввода на основании и печати существующих объектов. Smoke подтверждает техническую доступность выбранных действий, но не заменяет бизнес-критерии и проверки движений документов.

## Генерация и обновление

Настройки задают виды тестов и выходной каталог. Пакетное формирование выбирает типы объектов и действия. При генерации по метаданным сначала обновляется дерево метаданных, затем выбираются конкретные объекты/действия, формируются сценарии и отдельно создаются или обновляются feature-файлы. Тексты после генерации допускают корректировку.

Обработка подготовки данных может создать экспортные сценарии загрузки; это отдельная подготовка, а не гарантия наличия любых требуемых элементов. [Созданные данные и эталоны](test-data-strategies.md) определяют повторяемость расширенного smoke.

## Исключения из генерации

Файлы исключений имеют расширение `.txt`; имя начинается с вида метаданных, например `Справочники.txt` или `Документы.txt`. Одна строка — одно исключение; пустые строки и строки с `//` пропускаются.

```text
ИмяОбъекта
ИмяОбъекта.ФормаСписка
ИмяОбъекта.ФормаОбъекта
ИмяОбъекта.Запись
ИмяОбъекта.Копирование
ИмяОбъекта.ВводНаОсновании.ИмяДокументаОснования
ИмяОбъекта.Печать.ИмяПечатнойФормы
```

Первый вариант исключает объект целиком. Для `Запись` уточнение различает группу/элемент; отсутствие уточнения распространяется на оба. Для ввода на основании и печати отсутствие уточнения исключает все соответствующие варианты объекта. Это синтаксис исключений генератора, отдельный от [тегов отбора сценариев](tags-and-selection.md).

## Копирование требует доказанного исходного объекта

Документация описывает шаг копирования через команду формы с полным именем метаданных. Он сначала ищет команду на открытой форме, затем может открыть список. Успех требует нового окна формы копии, а не только нажатой кнопки. Для группы иерархического справочника fallback через список не применяется; для элемента он действует на текущую строку списка. Поэтому произвольная текущая строка не является корректной fixture.

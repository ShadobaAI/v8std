# Выполнение сценариев: отбор, остановка, таймауты, повторы и статусы

Справочная переработка текстов MainHelp 1.2.043.1, глава 02. Названия JSON-полей и элементы, видимые только на изображениях уроков, здесь не восстановлены. Рекомендации источника относятся к этой редакции и не определяют фактические настройки другого релиза.

## Выбрать объём запуска и порядок

Редактор выполняет один feature за раз, хотя внутри него могут быть многие сценарии. Загрузка каталога с подкаталогами переключает Vanessa в дерево и делает редактор недоступным до обратного перехода. При переходе из дерева в редактор открывается feature активной строки.

Непустой список имён сценариев ограничивает выполнение этими именами, сохраняя порядок сценариев внутри feature. Список feature выполняется в порядке списка; элементом может быть полный путь, имя файла без пути или имя фичи из содержимого.

Исключающие теги убирают сценарии при совпадении у сценария или feature. «Теги для запуска» оставляют сценарии при совпадении у сценария или feature. При противоречии двух фильтров руководство отдаёт приоритет второму — тегам для запуска.

Источники: [урок 63][s63], [урок 32][s32], [урок 37][s37].

## Остановиться в нужном месте и сохранить диагностический контекст

Остановка сессии при первой ошибке удобна для немедленного исправления. Отдельное окно остановки помогает, когда клиент перекрыл менеджер; опция быстрой реакции на «Стоп» рекомендована справкой. Кнопка остановки сценариев отличается от остановки записи действий.

F9 переключает точку останова текущей строки; выполнение прерывается на ней. Список точек позволяет перейти к точке или удалить все. Точки доступны также в отображаемых строках подсценариев. F8 последовательно переводит к строкам с ошибками. Очистка раскраски через Alt+C сбрасывает цвета результатов строк, а не описывает повторное выполнение.

Источники: [урок 14][s14], [урок 19][s19], [урок 70][s70], [урок 60][s60], [урок 58][s58].

## Настроить ожидания и повторы под наблюдаемую нестабильность

Количество попыток сценария по умолчанию равно 1. Значение больше 1 повторяет неуспешный сценарий. Другая настройка повторяет простое действие формы — ввод, нажатие и т.п. — через одну секунду после неудачи. Это разные уровни повторения.

Есть отдельное ожидание нового окна, добавочная пауза для инициализации формы и таймаут асинхронных шагов. Эффективный таймаут асинхронного шага — максимум общей настройки и времени, переданного самому шагу. Верхняя длительность элементарного действия вызывает исключение по истечении ненулевого ограничения; ноль отключает проверку.

Для CI справка рекомендует увеличивать попытки действий, ожидание окна и таймаут асинхронных шагов. Конкретные значения она не задаёт. При затирании введённого текста после серверного вызова есть механизм изменения свойства «ОбновлениеТекстаРедактирования» после шага «Тогда открылось окно»; он требует VAExtension в клиентской базе.

Источники: [урок 21][s21].

## Управлять скоростью и наглядностью

Асинхронный режим с паузой между шагами искусственно замедляет демонстрацию; минимальная пауза 0,1 секунды. Для обычной работы и CI справка рекомендует его выключать. Это настройка скорости выполнения, отдельная от таймаута ожидающих асинхронных шагов.

Обновление дерева повышает наглядность и может снижать скорость; действует только в режиме дерева. Обновление статистики можно отключить при очень большом числе сценариев ради небольшого ускорения. Расширенные сообщения помогают выяснить, почему feature не загружается. Звук завершения не требует синтеза речи; запись событий в журнал регистрации рекомендована для CI.

Источники: [урок 15][s15], [урок 17][s17], [урок 18][s18], [урок 16][s16].

## Различать результат и дополнительные режимы выполнения

Для неизвестного шага отдельный флаг выбирает статус «ошибка» вместо «не реализовано»; руководство рекомендует включить его. Другой режим различает падение шага «Тогда» как «ошибка», остальных ключевых слов — как «сломано». Устаревшая дополнительная колонка ошибки оставлена для совместимости дерева.

Паузы через ping нужны только без VanessaExt. По необходимости можно запретить перезапись переменных и обновлять данные таблиц перед чтением. Передача данных макета через VAExtension рекомендована при установленном расширении в клиентской базе.

Источники: [урок 22][s22], [урок 14][s14], [урок 20][s20].

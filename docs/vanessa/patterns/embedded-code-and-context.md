# Встроенный код в сценарии: контекст менеджера и TestClient

## Какой код в какой базе работает

| Механизм | Где выполняется |
| --- | --- |
| Клиентский код менеджера | В сеансе, в котором запущена Vanessa |
| Серверный код менеджера с объектом Vanessa | В серверном контексте объекта обработки |
| Серверный код менеджера без объекта Vanessa | В серверном контексте базы менеджера |
| Клиентский/серверный код через VAExtension | В соответствующем контексте базы TestClient |

Серверный API тестируемой конфигурации доступен в базе менеджера только если нужная конфигурация действительно находится в этой базе. При разных базах менеджер не становится клиентской базой из-за открытого соединения TestClient.

Inline-код ухудшает читаемость сценария. Руководство предлагает для повторяющегося поведения отдельный шаг или [экспортный сценарий](subscenarios-and-libraries.md). Это выбор способа организации теста, а не основание изменять код продукта.

## Передача значения без текстовой подстановки

FAQ показывает обмен через реквизит объекта обработки. Фрагмент относится к API Vanessa в документированной редакции:

```gherkin
И я запоминаю строку "НужнаяСтрока" в переменную "ИмяПеременной"
И я выполняю код встроенного языка
"""bsl
    Ванесса.Объект.ЗначениеНаСервере = Контекст.ИмяПеременной;
"""
И я выполняю код встроенного языка на сервере
"""bsl
    Объект.ЗначениеНаСервере = "Новое значение";
"""
И я выполняю код встроенного языка
"""bsl
    Контекст.ИмяПеременной = Ванесса.Объект.ЗначениеНаСервере;
"""
```

Это особенно полезно для сложной строки: текстовая подстановка кавычек и переводов строк в выражение может изменить код. [Многострочный параметр](variables-and-parameters.md) и значение переменной — разные механизмы.

## Состояние объекта и проверка проведения

Урок FAQ не обещает готового шага «проверить проведение по номеру». Описанная композиция: найти нужный документ → прочитать его состояние через VAExtension → проверить логическую переменную `Проведен`. Она применима и при разных базах. Сокращение через серверный контекст менеджера применимо только к варианту с одной базой.

Создание/проведение/пометка объекта, выполнение метода формы и запись реквизита имеют реальные побочные эффекты, даже если шаг содержит слово «выражение». [Стратегия данных](test-data-strategies.md) относится к этим действиям так же, как к записи через UI.

## Настройки во время исполнения

Документация описывает шаги изменения флага, числовой и строковой настройки Vanessa и сохранения прежнего значения в переменную. Имя настройки выясняется в форме через `Alt+H`. Сигнатуры конкретных шагов в соответствующем уроке показаны только картинками; это не универсальная JSON Schema.

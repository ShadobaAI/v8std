# Собрать feature: секции, Контекст, имена сценариев и группы шагов

Основание: MainHelp 1.2.043.1 и учебные feature этой редакции. Описания секций и отступов — документированное поведение; выбор декомпозиции — рекомендация. Vanessa использует Turbo Gherkin; методология BDD допустима, но не обязательна. Подключённые шаги и синтаксис своей версии проверяйте в runtime.

## Разложить текст по секциям

В начале можно явно задать `# language: ru`; без директивы в этой справке язык по умолчанию русский. Затем идут необязательные теги feature. `Функциональность:` с названием обязательна и встречается один раз. Описание роли, цели и пользы необязательно. Далее могут идти `Переменные:`, `Контекст:` и сценарии согласно стилю проекта.

После `Сценарий:` нужно имя, уникальное внутри feature, затем шаги. Теги сценария ставятся непосредственно перед его объявлением. Не путайте текст бизнес-описания с исполняемыми шагами.

## Подготовить каждый сценарий через Контекст

`Контекст:` выполняется перед **каждым** сценарием feature. Секция необязательна; если объявлена, нужен хотя бы один шаг. В файле без сценариев Контекст не выполняется. Это не однократная инициализация всего набора.

Минимальный пример на шагах работы со строковыми переменными из учебной библиотеки:

```gherkin
# language: ru
Функциональность: Сохранение строки

Контекст:
    И я запоминаю строку "готово" в переменную "Ожидание"

Сценарий: Строка_1
    И я запоминаю строку "готово" в переменную "Результат"
    Тогда переменная "Результат" имеет значение "$Ожидание$"
```

Подключение TestClient и закрытие окон в Контексте — примеры upstream, а не обязательная очистка любой базы. Подготовка должна соответствовать данным и принадлежащим тесту окнам; см. [стратегии данных](test-data-strategies.md).

## Сгруппировать шаги и сохранить их выполнение

Иерархия групп задаётся отступами, если у feature есть `@tree` либо включена настройка «тег tree включен по умолчанию». Без обоих условий строки считаются обычными шагами. Сам заголовок группы **не выполняется**: если следующий шаг сдвинуть глубже, предыдущая строка может случайно стать группой и перестать исполняться.

```gherkin
# language: ru
@tree
Функциональность: Явные группы
Сценарий: Сохранение результата
    * Подготовка значения
        И я запоминаю строку "готово" в переменную "Результат"
    * Проверка результата
        Тогда переменная "Результат" имеет значение "готово"
```

Звёздочка в начале имени группы рекомендована, но не обязательна; допускаются вложенные группы. Документация рекомендует табы; проектный стиль сохраняйте. В одном feature нельзя смешивать табы и пробелы как способ задания отступов. В примерах выше везде пробелы.

## Не создать конфликт имён и смыслов шагов

Число, отделённое пробелом или табом от остального имени сценария, распознаётся как параметр. Поэтому `Сценарий 1` и `Сценарий 2` способны конфликтовать; для простого номера учебный пример использует `Сценарий_1` и `Сценарий_2`.

Смена `Дано` на `Когда` или `Тогда` сама по себе не меняет выполняемое действие. Ключевое слово служит читаемости; проверка должна обеспечиваться реализацией шага, а не словом «Тогда». Точный текст ищите в подключённой библиотеке: [подсценарии и библиотеки](subscenarios-and-libraries.md).

Для вариантов данных используйте [структуру сценария](scenario-outlines.md), для фильтрации — [теги и выбор запуска](tags-and-selection.md).

# Собрать понятную видеоинструкцию: текст, озвучка, группы и циклы

Основание: snapshot `MakeAutoVideo.md`. Документ содержит исторические компоненты и явно помеченные устаревшие режимы; это recipes авторинга, а не актуальный список версий/тарифов облачных сервисов. Раздел о циклах ограничен версиями **после 1.2.042.19**. Наличие директивы не подтверждает готовность ПО и настроек: [поставка видео и автоинструкций](video-and-instructions.md).

## Разделить поведение теста и представление инструкции

Директивы комментария и теги ставятся перед нужным шагом/группой. Они меняют представление в автоинструкции; не отключайте ими обязательные проверяющие шаги ради «чистого» ролика.

| Директива | Эффект |
| --- | --- |
| `#[autodoc.text]` | Заменяет текст шага для инструкции |
| `#[autodoc.ignorestep]` | Шаг/группа выполняется, но не попадает в итоговый ролик |
| `#[autodoc.mute]` | Шаг выполняется без озвучки |
| `#[autodoc.donotscale]` | Отключает сжатие времени шага/группы для синхронизации с голосом |
| `#[autodoc.groupsteps]` | Представляет группу одним шагом; без текста использует имя группы |

`ignorestep` не равен пропуску исполнения, а `mute` не равен исключению из ролика. Это важно при чтении отчёта: отсутствие действия в видео само по себе не устанавливает, выполнялось ли оно.

## Написать текст через параметры шага

В `autodoc.text` `%1`, `%2` заменяются параметрами следующего шага; выражения в квадратных скобках вычисляются. Для буквальных квадратных скобок в исходнике показано экранирование.

```gherkin
#[autodoc.text] В интерфейсе я выбираю %2 и %1
Когда В командном интерфейсе я выбираю "Раздел" "Команда"
```

Это пример генерации подписи; названия раздела/команды нужно получить из целевого UI. Встроенные выражения в подписи должны быть осознанными: они вычисляются, а не просто печатаются. Не подменяйте ожидаемый результат вычисленным текстом диктора.

Для отключения слайдов предусмотрены `#[autodoc.ignore.scenarioslide]` перед объявлением сценария, `#[autodoc.ignore.featureslide]` перед объявлением функциональности и `#[autodoc.ignore.finalslide]` в позиции, описанной источником перед функциональностью.

## Сгруппировать рассказ и оставить служебные действия исполняемыми

Настройка «Группа шагов как шаг» превращает группы первого уровня в шаги автоинструкции. Для конкретной группы можно задать явный текст:

```gherkin
#[autodoc.groupsteps] Подготовка значения
* Подготовка
    И я запоминаю строку "готово" в переменную "Результат"
```

Фрагмент предполагает включённый разбор групп (`@tree` либо настройку); см. [структуру feature](feature-sections.md). Директива объединяет представление действий, а не меняет область assertions. Перед необходимым служебным шагом можно поставить `#[autodoc.ignorestep]`, сохранив его в сценарии и отчёте выполнения.

## Выбрать озвучку и не зависеть от случайных настроек

TTS необязателен: для ролика без диктора снимается «Делать озвучку TTS». При включённой озвучке «Тест голоса» позволяет проверить фактическое произношение. Кэш TTS и видеовставок ускоряет сборку и уменьшает повторные обращения к внешнему генератору речи.

Источник показывает отдельные теги шага `@YandexTTS:` и `@AmazonTTS:`; в развёрнутой форме параметры разделены точкой с запятой, у Yandex указаны `voice`, `emotion`, `speed`, у Amazon — `voice`, `lang`. Имена голосов и поддержку параметров подтвердите для выбранного движка/runtime: исторический пример не доказывает текущую доступность внешнего API. Credentials принадлежат настройкам окружения, а не feature или общему корпусу.

Пустая группа описана как способ выполнить действия без текста диктора. Используйте её только при понятной семантике групп, иначе неправильный отступ может исключить исполнение строки.

## Управлять видео в цикле и экспортном сценарии

Для раздела источника «после 1.2.042.19» задана настройка `ЗаписьВидеоГруппаШаговКакШаг: true`. Вместо обычной группы первого уровня внутри цикла предлагается `#[autodoc.groupsteps]`. Шаг `Дано текст диктора "Текст"` начинает запись сцены; источник также описывает вариант без текста с дальнейшей обработкой через словарь замен.

`@StartRecordVideo` и `@StopRecordVideo` управляют включением фрагмента **в видеоинструкцию**, в том числе в экспортном подсценарии. Они имеют приоритет перед `#[autodoc.ignorestep]` группы. Позднейший шаг текста диктора способен снова запустить запись сцены, поэтому не считайте Stop постоянным глобальным запретом до конца теста.

`@recordvideo` решает другую задачу — диагностическую запись выполнения; сам по себе не включает фрагмент в автоинструкцию. См. [диагностические теги](tags-and-selection.md).

Для табличного цикла можно отделить данные UI-действий от описаний сцен, эффектов и озвучки; повторяемое управление сценой вынести в [экспортный сценарий](subscenarios-and-libraries.md). Проверяйте порядок и результат, не пытайтесь исправлять видеомонтажом ошибку сценария.

## Отличить удачный монтаж от успешного теста

В режиме отладки с записью источник описывает обрезку массива шагов от точки запуска до остановки. Ролик продолжения со строки не доказывает полный прогон с начала. Критерий прохождения устанавливается результатами и assertions, а не наличием готового видео.

Каталог временных файлов очищается перед каждой сборкой видео: он должен быть отдельным рабочим каталогом профиля. Настройки частоты кадров, экрана и ускорения выбирают под нужный ролик; старые точные рекомендации не превращаются в обязательную политику всех проектов.

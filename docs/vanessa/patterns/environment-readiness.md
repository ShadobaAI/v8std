# Окружение Vanessa: менеджер, TestClient, MCP и запуск

## Роли сеансов и компонентов

Менеджер тестирования содержит Vanessa и MCP-провайдеры; TestClient — тестируемое приложение. Эти сеансы могут находиться в разных базах. VanessaExt является внешней компонентой, VAExtension расширяет возможности клиентской базы, а MCP devkit обеспечивает MCP в сеансе. Установка одного из компонентов не доказывает наличие остальных.

База, путь платформы, обработка, адрес MCP, имя клиента, features и результаты являются параметрами конкретного окружения. Порты примеров не определяют фактический адрес. [Профиль клиента](test-client-profiles.md) и фактическое запущенное приложение могут различаться после изменения настроек.

## Внешняя и встроенная обработка

Документированные варианты запуска различаются способом открытия Vanessa:

```text
ENTERPRISE /TESTMANAGER /Execute EPF_PATH
ENTERPRISE /TESTMANAGER /URL NAVIGATION_URL
/C "runMcp;mcpPort=MCP_PORT"
/IBConnectionString "File=""BASE_PATH"";"
```

Для внешней обработки нужен готовый EPF; навигационная ссылка относится к встроенной обработке конкретной конфигурации. Документация платформы определяет приоритет `/Execute` над `/URL`, поэтому совместное указание не является двумя независимыми способами открытия. Кавычки внутри строки соединения удваиваются; CRT-экранирование через обратную косую черту имеет другой смысл.

Наличие `/URL` в аргументах не доказывает открытия встроенной формы: руководство различает внутренние/внешние ссылки и случаи игнорирования внутренней ссылки. Изменение способа открытия меняет контракт запуска; оно не является эквивалентной скрытой подстановкой.

## Доступность MCP и готовность UI

Открытый TCP-порт означает только наличие слушателя. Инициализированный MCP может зарегистрировать лишь часть провайдеров. Полный `tools/list`, сведения об окружении, состояние Vanessa, действительное подключение TestClient и доступные расширения отвечают на разные вопросы о готовности.

Карточки `vanessa:mcp:*` описывают определённую редакцию документации; точные параметры задаёт текущая схема runtime. README devkit отдельно предупреждает о нестабильном интерфейсе. Неизвестная версия или отсутствующее поле не являются значением по умолчанию.

Интерактивный и пакетный режимы отличаются автоматическим выполнением и завершением сеанса. Загрузка `VAParams` без `StartFeaturePlayer` загружает настройки, не запуская сценарии. Подробности — [конфигурация и CI](configuration-and-ci.md). Различие режимов Editor конкретной версии описано в [исполнении](execution-debugging.md).

## Граница справки

Выбор профиля, проверка полномочий, владение процессом и блокировка управления относятся к навыку и инструментам исполнения. Этот рецепт описывает связи и контракты компонентов, а не обязательный агентский workflow.

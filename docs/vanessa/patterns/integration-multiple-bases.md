# Интеграционные тесты: несколько баз, роли и обмен данными

## Сценарий верхнего уровня

Vanessa поддерживает интеграционные сценарии с двумя и более базами и внешними сервисами. Руководство предлагает сначала описать поведение на высоком уровне и вынести детали в [подсценарии](subscenarios-and-libraries.md).

```text
Подготовка данных в системе-источнике
Инициирование выгрузки
Ожидание наблюдаемого результата обмена
Подключение к системе-получателю
Инициирование/ожидание загрузки
Проверка полученных данных и бизнес-результата
```

Это схема, а не готовые имена стандартных шагов. Обмен можно инициировать через UI или кодом; проверки результата остаются отдельной частью сценария.

## Один управляемый TestClient в текущий момент

Один сценарий управляет одним клиентом тестирования одновременно и последовательно переключает подключения библиотечными шагами. Это не запрет иметь несколько запущенных клиентов. В проверках ролей FAQ описывает отдельные TestClient на разных портах и переключение между ними.

При переключении меняются активное окно, база и пользовательский контекст. Ссылка на объект, переменная либо текущая строка одного клиента не доказывают соответствие объекта в другом. [Шаг в контексте менеджера](embedded-code-and-context.md) по-прежнему выполняется в базе менеджера.

## Данные и проверяемый результат

Идентификатор тестового набора и ожидаемый результат нужны на обеих сторонах обмена. [Подготовка данных](test-data-strategies.md) может быть комбинированной: сценарий, внешний файл или эталонная база. «Запуск обмена завершился» слабее проверки, что нужная запись получена и обработана.

## RAT — отдельная зависимость

RAT (Remote API for Testing) упомянут в документации как отдельное расширение для тестирования интеграций. Короткая страница Vanessa содержит только назначение и внешние ссылки. Она не описывает API RAT, порядок его установки или полномочия в конкретной базе; наличие Vanessa не подтверждает наличие RAT.

Связанные темы: [профили клиентов](test-client-profiles.md), [ожидания](synchronization-and-waits.md), [электронная почта](email-testing.md).

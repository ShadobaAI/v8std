# Редактор Vanessa: загрузка feature, сохранение, поиск, подсценарии и инструменты

Справочная переработка текстов MainHelp 1.2.043.1, главы 02 и 13. Названия JSON-полей и элементы, видимые только на изображениях уроков, здесь не восстановлены. Рекомендации источника относятся к этой редакции и не определяют фактические настройки другого релиза.

## Открыть, сохранить и перечитать нужный файл

На закладке «Запуск сценариев» находятся панель инструментов, Monaco-редактор, имя текущего файла и статистика. Один feature открывается для редактирования и выполнения. Загрузка каталога рекурсивно загружает feature в дерево: редактор не выполняет несколько feature одновременно. Обратный переход открывает файл активной строки дерева.

Сохранение текущего файла, «Сохранить как», перечитывание с диска и «перечитать и выполнить» — разные команды. Изменение файла внешним редактором и сохранение буфера Vanessa поэтому не равнозначны. Есть отдельные команды запуска всех сценариев текущего feature и остановки, переход в дерево с текущим feature. Markdown открывается только для просмотра; начальная страница содержит частые команды и недавно открытые файлы.

Источники: [урок 79][s79], [урок 63][s63], [урок 62][s62].

## Быстро изменить текст и найти отличия

Ctrl+Z отменяет изменение, Ctrl+Y возвращает отменённое; Ctrl+X/C/V работают с буфером. Ctrl+F ищет, Ctrl+H открывает замену. Ctrl+/ переключает комментарий выделенных строк. Отдельная команда обрамляет выделенные строки вертикальными чертами, превращая их в таблицу Gherkin.

«Сравнить с другим фича файлом» показывает различия текущего текста и файла. Настройка выбирает два столбца либо различия внутри текста; кнопки переходят между различиями. Масштаб можно увеличить, уменьшить и сбросить; тема сохраняется в настройках. Сворачивание всех групп, раскрытие следующего уровня и полное раскрытие помогают просматривать вложенность.

Источники: [урок 61][s61], [урок 69][s69], [урок 68][s68], [урок 65][s65], [урок 72][s72], [урок 73][s73], [урок 64][s64], [урок 71][s71].

## Включать подсказки и диагностику осознанно

Подстановка данных текущей формы в параметры шагов опрашивает TestClient раз в секунду. Для Web нужна осторожность: ответы могут быть заметно медленнее тонкого клиента. Без опции остаются значения из описания шага. Отображение строк подсценариев помогает при глубокой вложенности, но справка рекомендует включать его по необходимости.

Значения переменных справа от строк и автоматическая проверка шагов рекомендованы для отладки. Красное подчёркивание может означать отсутствие шага в подключённой библиотеке; выключение проверки лишь скрывает подчёркивание. Настраиваются миниатюра, замена табуляций пробелами, видимость пробелов, положение вкладок, начальная страница, тема, видимость кнопок и все доступные настройки Monaco. Опция Esc генерирует закрытие формы Vanessa.

Источники: [урок 2][s2], [урок 73][s73].

## Найти feature и изучить доступный шаг

«Дерево каталогов» получает корень feature и открывает файл в редакторе; активный файл выделяется жирным. Поиск ранжирует совпадение имени раньше совпадения содержимого.

«Библиотека шагов» показывает доступные шаги. «Показать краткую информацию о шаге» сообщает, в частности, модуль реализации. «Исследователь формы» показывает поля и состояние TestClient. Команды получения шагов умеют сформировать проверку всей формы, шапки, текущего элемента, сообщений, навигационной ссылки или текущего окна. «Запомнить/Забыть состояние» предназначены для исследования изменений формы; табло переменных позволяет смотреть и редактировать значения.

Перевод сначала требует выбора языка; первое чтение переводов может быть долгим. Переводятся шаги по таблицам соответствий Vanessa, а не произвольный естественный текст.

Источники: [урок 77][s77], [урок 72][s72], [урок 59][s59].

## Выполнить часть сценария и перейти к связанному файлу

Команды контекстного меню различаются границами выполнения:

| Задача | Команда | Граница действия |
| --- | --- | --- |
| Продолжить текущий сценарий с текущего шага | Ctrl+F5 | Следующие сценарии не выполняются |
| Продолжить с шага и затем выполнить следующие сценарии | Ctrl+Shift+F5 | После текущего выполняются следующие сценарии |
| Выполнить один сценарий с начала | Alt+F5 | Только текущий сценарий |
| Выполнить один шаг | F11 | Только один шаг |
| Выполнить выбранный фрагмент | «Выполнить выделенные строки» | Выделенные строки; это отдельная команда |
| Открыть объявление подсценария | F7 | Новая вкладка на строке объявления |
| Открыть текущий feature во внешнем редакторе | Shift+F7 | Приложение, ассоциированное с расширением feature |
| Открыть каталог текущего feature в проводнике | Ctrl+F7 | Каталог файла |

Частичное выполнение предназначено для исследования и отладки; его результат не устанавливает успешность полного сценария. Источники: [выполнение из контекстного меню][s13run], [переходы к файлам][s13files].

Ctrl+Shift+T открывает специальный редактор таблиц Gherkin. В нём меняются значения ячеек, видимость и порядок колонок, добавляются колонки; отдельное подтверждение помещает отредактированную таблицу обратно в текст сценария. Это отличается от обрамления выделенных строк вертикальными чертами. Источник: [редактор таблиц][s13tables].

Ctrl+J заменяет известный шаг поиска элемента по внутреннему имени на шаг поиска того же элемента по заголовку; повторный вызов выполняет обратную замену. В TestClient должно быть активно окно с соответствующим элементом. Команда не является общим поиском новой замены устаревшему элементу. Источник: [имя и заголовок элемента][s13name].

## Создать собственный шаг и подключить библиотеку

«Генератор EPF» предлагает управляемую или обычную форму и разбиение кода на области; управляемая форма и области рекомендованы справкой. Режим вывода текста модуля вместо генерации помогает, если EPF на машине не создаётся. В поле версии платформы задаётся каталог установленной платформы для генерации. Нужны толстый клиент и возможность запуска файловой базы с лицензией.

В «Библиотеках» для основной поставки, в отличие от Single, обычно уже создан путь основной библиотеки. Дополнительные каталоги подключают для собственных шагов и общих экспортных сценариев. Формат JSON-поля и рекурсивность поиска в этом уроке не описаны.

Источники: [урок 76][s76], [урок 75][s75].

## Использовать панель Git как ограниченный клиент

Панель Git работает с указанным каталогом репозитория: читает статусы, добавляет/убирает из индекса, создаёт коммит с сообщением, задаёт автора, переключает ветки, выполняет Pull и Push. Она покрывает частые операции создания сценариев и не заменяет полный Git-клиент. Отображение кнопок панели редактора можно сократить для маленького экрана.

Источники: [урок 78][s78], [урок 73][s73].

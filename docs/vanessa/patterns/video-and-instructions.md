# Автоинструкции Vanessa: HTML, Markdown, озвучка, видео и эмуляция действий

Справочная переработка текстов MainHelp 1.2.043.1, глава 02. Названия JSON-полей и элементы, видимые только на изображениях уроков, здесь не восстановлены. Рекомендации источника относятся к этой редакции и не определяют фактические настройки другого релиза.

## Собрать HTML или Markdown из выполнения сценария

Формирование HTML включается флагом и требует каталога. Во время выполнения снимаются скриншоты шагов или групп, затем строится итоговая инструкция. Варианты оформления: простая последовательность текста/снимков, страница со стилями либо 3D-карусель изображений. Для вариантов с оформлением можно задать CSS. Команда редактирования открывает CSS, другая выгружает предопределённый макет в файл и прописывает его путь.

Markdown формируется аналогично в отдельный каталог. Есть автонумерация описаний, включение имени фичи и сценария. Группа шагов может стать одним пунктом инструкции; тег screenshot выбирает снимок внутри группы. Несколько отмеченных шагов дают несколько снимков. HTML умеет произносить шаг по клику на изображение с выбором голоса, темпа и диапазона.

Источники: [урок 3][s3].

## Подготовить озвучку групп шагов

Кнопка озвучки переключает тот же флаг, что настройка речи при выполнении. Нужен настроенный движок генерации голоса. Текст диктора помещается в строки групп, начинающиеся со звёздочки, а действия — внутрь групп. Это позволяет выполнять действия во время произнесения текста. Объединение группы в один пункт автоинструкции рекомендовано справкой.

Озвучка в реальном времени полезна для проверки текста до сборки видео. Для промежуточных аудиофайлов задаётся каталог. Среди движков перечислены Yandex SpeechKit, 1С, Amazon, Сбербанк и произвольная EPF-реализация; Microsoft в этой редакции назван устаревшим и не рекомендован. Текущие параметры можно проверить встроенными элементами проверки. Сам перечень не подтверждает актуальную доступность внешних облачных сервисов.

Источники: [урок 66][s66], [урок 6][s6], [урок 7][s7].

## Исправить произношение и не генерировать звук повторно

Список словарей содержит пути файлов. В каждой строке исходное значение и коррекция разделены вертикальной чертой. Иллюстрация формата, а не готовый словарь:

```text
исходное произношение|коррекция произношения
```

Кэширование включается флагом и требует каталога кэша: оно позволяет повторно использовать аудио при платных сервисах речи. Это отдельная настройка от временного каталога озвучки и от кэша интерактивной справки.

Источники: [урок 8][s8], [урок 5][s5].

## Выбрать механизм взаимодействия для автоинструкции

UI Automation предназначен для тонкого/толстого клиента: часть обычных библиотечных шагов начинает искать элементы через UI Automation, давая движение мыши и анимацию кликов.

Для Web/Chrome режим работы через специальный порт позволяет искать элементы непосредственно на странице браузера. Нужна команда запуска Chrome с соответствующими ключами. Опция продолжения без ошибки при ненайденном элементе применяется по ситуации; она меняет реакцию сценария на поиск. Коэффициент масштаба корректируется при масштабировании ОС.

Поиск картинок через VanessaExt имеет числовую добротность. Старый вариант SikuliX выбирается выключением режима компоненты и не рекомендован справкой. Эмуляция клавиатурного ввода требует VanessaExt.

Источники: [урок 4][s4], [урок 11][s11], [урок 24][s24], [урок 10][s10], [урок 12][s12].

## Настроить мышь и различить видео от отчёта

Эмуляция мыши применяется к обычным шагам основной библиотеки. Смещения координат нужны только для компенсации положения курсора. Скорость задают числом микродвижений и паузой в миллисекундах. Анимация клика имеет включение, цвет, радиус, длительность, толщину и прозрачность; результат можно проверить гиперссылкой.

Для подготовки автоинструкций доступны «Озвучить текущую строку» и «Получить координаты области для скриншота». Урок настроек автовидео лишь направляет к отдельным материалам и не задаёт команду сборки или формат конфигурации. Видеозапись прохождения тестов — другой режим с FPS, командой и выходным каталогом; увеличение FPS повышает нагрузку.

Источники: [урок 13][s13], [урок 72][s72], [урок 9][s9], [урок 45][s45].

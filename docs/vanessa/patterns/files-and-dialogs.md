# Выбор и сохранение файлов: thin/thick, web и пути макетов

## Настольный клиент: подмена до открытия

Для тонкого и толстого клиента урок описывает специальный шаг выбора файла с единственным параметром — полным путём. Он применяется **до** действия, вызывающего диалог, как для открытия, так и для сохранения. При правильной подмене системный диалог на экране не появляется.

## Web-клиент: диалог сначала появляется

В веб-клиенте порядок другой: действие открывает диалог, затем вариант шага «я выбираю файл ВК» вводит путь эмуляцией клавиатуры. Для него нужны VanessaExt и активное окно браузера. Это не тот же алгоритм подмены, что у тонкого клиента.

В Markdown-уроке описаны названия и назначение, но полные сигнатуры показаны на изображениях. Для исполняемого текста нужен соответствующий установленной библиотеке стандартный шаг, а не восстановление сигнатуры по озвучке.

## Сохранение документа и эталон

Для поля текстового или табличного документа предусмотрен специальный механизм сохранения; конкретный шаг определяет формат и параметры. Сохранённый файл становится артефактом выполнения. Его назначение эталоном — отдельное решение о правильном результате.

В сравнении табличного документа MXL ищется по basename без расширения в корне проекта либо рядом с feature. [Произвольный каталог макетов](project-layout.md) без поддержки конкретного шага не подключается автоматически. Пути относятся к машине, на которой работает соответствующий механизм; клиентские файловые диалоги не доказывают существование файла на сервере.

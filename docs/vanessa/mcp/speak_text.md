# Vanessa MCP: speak_text

## Контракт и версия

Справочная карточка из `docs/AI/index.md`. Git revision неизвестна; точная редакция определена content_revision и input SHA-256 в manifest.json.
Версия runtime и JSON Schema этим snapshot не подтверждены. Полный контракт конкретного сервера публикуется в `tools/list` и `inputSchema`. Документированное описание ниже может раскрывать отдельные параметры и эффекты, но не устанавливает отсутствующие в нём типы, обязательность, enum или структуру ответа.

## Назначение, документированные параметры и ответ

Синтезирует переданный текст в речь и произносит его пользователю настроенным движком синтеза речи (настройки берутся с закладки "Сервис" - "Автоинструкции" - "Аудио" - "Озвучивание диктором"). Параметр **text** обязателен, максимум 500 символов. Полезно, чтобы голосом сообщить пользователю о завершении длинного задания, о необходимости принять решение или об ошибке. Фраза произносится асинхронно: ответ возвращается сразу после начала воспроизведения, а пока фраза звучит, повторный вызов инструмента возвращает ошибку - нужно дождаться окончания озвучки. Параметр **no_play** (boolean, по умолчанию false): если true, текст только синтезируется и сохраняется в кеш озвучки, без воспроизведения - полезно для прогрева кеша, последующий вызов с тем же текстом возьмёт озвучку из кеша без обращения к сервису синтеза. Прогрев требует включённого кеширования озвучки в настройках (Сервис - Автоинструкции - Аудио); в режиме обучения прогрев не работает. В режиме no_play ответ возвращается синхронно после завершения синтеза и может занять несколько секунд, а ограничение "пока фраза звучит, повторный вызов возвращает ошибку" не действует. Требует включённую внешнюю компоненту VanessaExt. Не работает в веб-клиенте и под Linux.

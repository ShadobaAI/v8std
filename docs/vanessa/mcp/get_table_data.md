# Vanessa MCP: get_table_data

## Контракт и версия

Справочная карточка из `docs/AI/index.md`. Git revision неизвестна; точная редакция определена content_revision и input SHA-256 в manifest.json.
Версия runtime и JSON Schema этим snapshot не подтверждены. Полный контракт конкретного сервера публикуется в `tools/list` и `inputSchema`. Документированное описание ниже может раскрывать отдельные параметры и эффекты, но не устанавливает отсутствующие в нём типы, обязательность, enum или структуру ответа.

## Назначение, документированные параметры и ответ

Получает данные из таблицы базы данных. Цель - понять какие тестовые данные уже есть в базе, чтобы лучше понимать какими данными заполнять объекты в тестах. Нужно указать Тип - **object_type**: 1 = Справочник, 2 = Документ, 3 = Перечисление, 4 = одна константа, 5 = все константы, 6 = Реквизиты объекта по навигационной ссылке, 7 = План видов характеристик, 8 = все справочники, 9 = все документы, 10 = все перечисления, 11 = все планы видов характеристик. Надо указать Вид - **object_name** (обязательный параметр для object_type 1-4 и 7). **limit** - сколько элементов возвращать (необязательный, по умолчанию 10). Для справочников будет возвращено Наименование, Код, Владелец, если такие поля есть у данного вида справочника. Если справочник подчинен другому справочнику, то должен быть параметр для указания владельца. Для документа будут возвращены Дата, Номер. Для справочников и документов будет также возвращена навигационная ссылка. Для документов можно передать **date_start** и **date_end** (оба необязательные, формат: "30.12.2025 15:45:55"). **name_filter** - отбор по наименованию элемента. Работает для Справочников и Планов видов характеристик. Для документов (object_type = 2) не применяется - у документов нет реквизита "Наименование", используйте **filter**, например filter="Номер = мп00-000001". Необязательный параметр. Нужен, чтобы проверить есть ли конкретный элемент в базе. **name_match_type** - режим сравнения для name_filter: **exact** (точное совпадение, по умолчанию), **partial** (частичное совпадение, подстрока в любом месте наименования), **starts_with** (наименование начинается со значения). Работает только совместно с **name_filter** (для Справочников и Планов видов характеристик; для документов не применяется). Необязательный параметр. **navigationLink** - навигационная ссылка на элемент справочника или документ (используется когда object_type = 6). **start_number** - начальный номер константы в диапазоне (1-based, используется только при object_type = 5). **end_number** - конечный номер константы в диапазоне (1-based, используется только при object_type = 5). Для планов видов характеристик (object_type = 7) возвращаются Наименование, Код, если такие поля есть у данного вида ПВХ, а также навигационная ссылка. Для справочников, документов и планов видов характеристик в ответе дополнительно возвращается общее количество элементов/документов в информационной базе (без учёта фильтров и параметра limit). **object_type** = 8 - возвращает список имён всех справочников в базе. **object_type** = 9 - возвращает список имён всех документов в базе. **object_type** = 10 - возвращает список имён всех перечислений в базе. **object_type** = 11 - возвращает список имён всех планов видов характеристик в базе. Ответ выводится таблицей Markdown (справочники, документы, константы), элементы перечислений - нумерованным списком "N. Имя — Представление". Данные читаются через служебную форму расширения; после вызова инструмент возвращает фокус окну, которое было активным до вызова.

# Vanessa MCP: execute_form_actions

## Контракт и версия

Справочная карточка из `docs/AI/index.md`. Git revision неизвестна; точная редакция определена content_revision и input SHA-256 в manifest.json.
Версия runtime и JSON Schema этим snapshot не подтверждены. Полный контракт конкретного сервера публикуется в `tools/list` и `inputSchema`. Документированное описание ниже может раскрывать отдельные параметры и эффекты, но не устанавливает отсутствующие в нём типы, обязательность, enum или структуру ответа.

## Назначение, документированные параметры и ответ

Выполняет последовательность действий с элементами формы клиента тестирования. Позволяет выполнить несколько действий за один вызов инструмента. Параметр **actions_json** (обязательный) - JSON-строка с массивом действий. Каждое действие в массиве содержит: **action** - тип действия (click_button, input_text, и т.д.), **element_name** - имя элемента формы, **table_name** - имя таблицы (если элемент в таблице), **value** - значение для ввода/выбора, другие параметры в зависимости от действия. При возникновении ошибки выполнение прерывается. Модальные диалоги: диалог проверяется перед каждым действием, после последнего действия и при ошибке действия (диалог может появиться с задержкой - после цепочки асинхронных обработчиков). Появление модального диалога приостанавливает цепочку: результат возвращается со статусом paused_modal_dialog (это не ошибка), в нём - выполненные действия, текст диалога, его кнопки и машиночитаемый остаток цепочки (блок json), выполненные действия повторять не нужно. Диалоги не закрываются автоматически: ожидаемый диалог закрывайте действием **manage_modal_dialog** прямо в цепочке сразу после действия, которое его вызывает; неожиданный - ответом на паузу (**manage_modal_dialog** через **manage_form_elements**) и продолжением остатка. Окна 'Выбор типа данных' и 'Список значений' диалогами не считаются - с ними работает вызывающая сторона. Веб-клиент: не поддерживается. Требует подключённого клиента тестирования.

# Vanessa MCP: manage_form_elements

## Контракт и версия

Справочная карточка из `docs/AI/index.md`. Git revision неизвестна; точная редакция определена content_revision и input SHA-256 в manifest.json.
Версия runtime и JSON Schema этим snapshot не подтверждены. Полный контракт конкретного сервера публикуется в `tools/list` и `inputSchema`. Документированное описание ниже может раскрывать отдельные параметры и эффекты, но не устанавливает отсутствующие в нём типы, обязательность, enum или структуру ответа.

## Назначение, документированные параметры и ответ

Универсальный инструмент для управления элементами формы клиента тестирования. Поддерживаемые действия (параметр **action**): **click_button** - нажатие на кнопку формы (требуется **element_name**), **input_text** - ввод текста в поле (требуются **element_name** и **value**; ввод не фиксирует значение - завершите ввод, например **simulate_tab**), **open_dropdown** - открыть выпадающий список (требуется **element_name**; у перечислений и других статических списков элементы видны сразу, у ссылочных полей с вводом по строке список наполняется только после ввода текста в поле - открытый без текста список пуст, это поведение платформы), **get_dropdown_state** - получить состояние открытого списка (требуется **element_name**; инструмент дожидается формирования открытого списка, т.к. наполнение после ввода текста асинхронное; если список всё ещё пуст, повторите вызов через несколько секунд), **select_from_dropdown** - выбрать значение из открытого списка (требуются **element_name** и **value**; перед выбором инструмент дожидается формирования списка), **set_value** - установить значение в поле одним действием (требуются **element_name** и **value**; для ссылочных полей с вводом по строке инструмент вводит текст, дожидается формирования списка и выбирает значение, при неудаче дожидается формирования и повторяет выбор), **open_choice_form** - открыть форму выбора для поля (требуется **element_name**), **set_radio_button** - установить переключатель (требуется **element_name**, имеет смысл только для полей шапки), **set_checkbox** - установить флаг (требуется **element_name**), **unset_checkbox** - снять флаг (требуется **element_name**), **toggle_checkbox** - переключить флаг на противоположное значение (требуется **element_name**), **click_hyperlink** - нажать гиперссылку (требуется **element_name**, опционально **hyperlink_title** или **hyperlink_index** (индекс с 0), имеет смысл только для полей шапки), **simulate_tab** - эмуляция перехода TAB (без параметров или с **tab_direction**), **activate_column** - активизировать колонку таблицы (требуются **table_name** и value - имя колонки: имя реквизита табличной части, полное имя поля формы или заголовок), **navigate_next_column** - переход к следующей колонке в таблице (эмуляция TAB, параметры: **table_name**), **navigate_previous_column** - переход к предыдущей колонке в таблице (эмуляция SHIFT+TAB, параметры: **table_name**), **start_edit_row** - начать редактирование строки таблицы (параметры: **table_name**, редактирование начнётся в текущей колонке таблицы; если текущая колонка не редактируется, сначала активизируйте редактируемую колонку действием **activate_column**; учтите: колонка в реальной форме может быть фактически нередактируемой, хотя по данным элемента формы этого не видно - **get_form_element_data** показывает обычные 'Вид: Поле ввода', 'Доступность: Да', 'ТолькоПросмотр: Нет' - тогда старт редактирования завершится ошибкой, это ожидаемая ситуация, и нужно выбрать другую колонку), **end_edit_row** - закончить редактирование строки таблицы (параметры: **table_name**), **navigate_to_row** - переход к строке таблицы по ключу (параметры: **table_name** и **row_criteria** в формате 'Колонка=Значение;Колонка2=Значение2'), **navigate_next_row** - переход к следующей строке таблицы (параметры: **table_name**), **navigate_previous_row** - переход к предыдущей строке таблицы (параметры: **table_name**), **choose_row** - выбрать текущую строку таблицы (эмуляция нажатия ENTER на текущей строке и колонке таблицы, параметры: **table_name**), **get_selected_rows** - вернуть значение выделенных строк таблицы (по умолчанию возвращается значение текущей строки, параметры: **table_name**), **create_new** - вызывает команду создания нового элемента у указанного поля шапки или поля таблицы (параметры: **element_name** обязательный, **table_name** опционально если элемент находится в таблице), **switch_tab** - переключиться на закладку (группу формы, параметры: **element_name** имя группы/закладки), **toggle_group** - развернуть/свернуть группу (параметры: **element_name** имя группы, **value** expand/collapse/toggle), **activate_header_element** - активизировать элемент шапки формы (параметры: **element_name**), **clear_field** - очистить поле (требуется **element_name**, опционально **table_name** для полей в таблицах), **clear_message_window** - очистить окно сообщений пользователю в текущем окне (не требует параметров), **select_from_form_dropdown** - выбрать значение из списка выбора формы (требуются только **value**), **add_row** - добавить строку в таблицу (требуется **table_name**; строка открывается на редактирование - заполните поля и вызовите **end_edit_row**; результат проверяется повторным чтением состояния таблицы), **copy_row** - скопировать текущую строку таблицы (требуется **table_name**; требуется платформа 8.3.25+; строка открывается на редактирование; если текущей строки нет - возвращается ошибка; результат проверяется повторным чтением состояния таблицы), **delete_row** - удалить текущую строку таблицы (требуется **table_name**; строку-адресат указать нельзя - чтобы удалить конкретную строку, сначала перейдите к ней, например **navigate_to_row**; перед удалением проверяется, что таблица не в режиме редактирования: начатое редактирование завершается автоматически, а если завершить не удалось - удаление отменяется; при множественном выделении возвращается ошибка; удаляемая строка возвращается в ответе компактной сводкой, полное представление - **full_row**=true; разрушительное действие - строка удаляется без подтверждения), **go_one_level_down** / **go_one_level_up** - перейти на уровень вниз/вверх в дереве (требуется **table_name**), **goto_first_row** / **goto_last_row** - перейти к первой/последней строке таблицы (требуется **table_name**), **goto_next_item** / **goto_previous_item** - перейти к следующему/предыдущему элементу таблицы (требуется **table_name**), **is_expanded** - вернуть признак развёрнутости текущей строки таблицы (требуется **table_name**), **select_all_rows** - выделить все строки таблицы (требуется **table_name**; возвращает количество выделенных строк; в веб-клиенте количество может обновляться с задержкой), **select_row** - установить выделение текущей строки таблицы (требуется **table_name**; требуется платформа 8.5.1+; не путать с **choose_row** - Выбрать, эмуляция ENTER), **set_cell_text** - ввести текст в поле ячейки таблицы (требуются **table_name**, **element_name** и **value**; явная пустая строка очищает ячейку; если строка ещё не редактируется, инструмент сам начинает редактирование; после ввода строка остаётся в режиме редактирования - завершите её **end_edit_row**; если колонка в реальной форме фактически нередактируемая (по данным элемента формы это не видно), старт редактирования завершится ошибкой - это ожидаемая ситуация, и нужно выбрать другую колонку; не работает в веб-клиенте), **set_order** - установить порядок таблицы по колонке (требуются **table_name** и **order** - имя колонки: имя реквизита табличной части, полное имя поля формы или заголовок; повторный вызов по той же колонке переключает направление сортировки - действие не идемпотентно; метод работает с таблицами-списками (динамическими списками), для табличных частей документов возможна ошибка "в элементе управления отсутствует указанное значение" - она возвращается с подсказкой), **switch_row_delete_mark** - переключить пометку удаления текущей строки таблицы (требуется **table_name**; поддерживается только для таблиц динамических списков, вопрос подтверждения платформы действие обрабатывает само - паузы на этом вопросе не будет; изменяет данные), **begin_edit_current_area** / **end_edit_current_area** - начать/закончить редактирование текущей области табличного документа (требуется **element_name** - поле табличного документа), **get_current_area_address** - вернуть адрес текущей области табличного документа (требуется **element_name**), **get_current_area_text** - вернуть текст области табличного документа (требуется **element_name**; опционально **area** - адрес области, без него возвращается текст текущей области), **get_doc_area_horizontal_size** / **get_doc_area_vertical_size** - вернуть размер области данных табличного документа по горизонтали/вертикали (требуется **element_name**), **get_formatted_string_hyperlink_presentations** - вернуть список представлений гиперссылок форматированной строки поля (требуется **element_name**; требуется платформа 8.3.25+), **set_area_text** - ввести текст в область табличного документа (требуются **element_name**, **area** - адрес или имя области, **value** - текст; явная пустая строка очищает область; не работает в веб-клиенте), **set_current_area** - установить текущую область табличного документа (требуются **element_name** и **area** - адрес или имя области), **cancel_edit** - отменить редактирование поля, ячейки таблицы или дополнения формы (требуется **element_name**, опционально **table_name** - имя таблицы, в которой находится элемент; для ячейки таблицы отменяется незавершённый ввод ячейки, строка при этом сохраняется - чтобы удалить добавленную строку, используйте **delete_row**), **current_opened** - вернуть признак открытости группы (требуется **element_name**; до платформы 8.3.27.2224 результат мог быть неверным), **decrease_value** / **increase_value** - уменьшить/увеличить значение поля (требуется **element_name**), **goto_value** - установить значение полосы регулирования в процентах (требуются **element_name** и **percent** - число 0-100), **current_modified** - вернуть признак модифицированности активной формы (без параметров), **execute_choice_from_menu** - выполнить выбор из раскрытого меню формы (требуется **menu_path** - путь к пункту меню, уровни разделяются '\n'; меню нужно открыть предыдущим действием, для кнопок командной панели используйте **click_button**), **goto_date** - выполнить переход к дате в календаре (требуются **element_name** и **date** - дата в формате 'ДД.ММ.ГГГГ'), **manage_modal_dialog** - ответить на модальный диалог нажатием кнопки (требуется **element_name** - заголовок или имя кнопки диалога, например 'ОК', 'Да', 'Нет'; сравнение без учёта регистра; диалог ищется среди всех окон, включая окна выбора; **expect_text** задаёт ожидаемую подстроку текста диалога, **optional**=true отключает ошибку, если диалога нет). Модальные диалоги в **execute_form_actions**: диалоги не закрываются автоматически; ожидаемый диалог закрывайте действием **manage_modal_dialog** прямо в цепочке сразу после действия, которое его вызывает, неожиданный - ответом на паузу и продолжением остатка. Правило выбора действия по типу поля (относится и к полям шапки, и к полям таблиц): ссылочные типы (Справочник, Документ, План видов характеристик) - **set_value** без **exact_match** (по умолчанию): инструмент вводит значение как текст и выбирает элемент из сформированного по нему списка, для поля таблицы - с параметром **table_name**; перечисления и статические списки - **set_value** с **exact_match**=true (точное значение из уже сформированного списка, без ввода текста); наполнение выпадающего списка: у перечислений элементы есть сразу после открытия списка (open_dropdown), у ссылочных полей с вводом по строке список наполняется только после ввода текста в поле и данные приходят асинхронно - set_value, select_from_dropdown и get_dropdown_state сами дожидаются формирования списка, а открытый без текста список ссылочного поля пуст - это нормальное поведение платформы; простые типы (строка, число, дата) - **input_text** для полей шапки и **set_cell_text** (или **input_text** с **table_name**) для ячеек таблиц: списка выбора у них нет, **set_value** для них не работает; ввод текста в ссылочное поле значение не выбирает - поле останется пустым, и для шапки, и для таблицы; фиксация значения после ввода: **simulate_tab** для полей шапки, для таблиц - **end_edit_row** (обязательно, если заполняется последнее редактируемое поле строки, иначе значение фиксирует переход к следующему полю); строку табличной части заполняйте одним вызовом **execute_form_actions** в две фазы: **add_row** -> **set_value** (ссылочные ячейки) -> **end_edit_row** -> **activate_column** (нужная колонка) -> **start_edit_row** -> **set_cell_text** (число, строка, дата) -> **end_edit_row**. Завершение редактирования между ссылочными и простыми ячейками обязательно: ячейка ссылочного типа удерживает фокус, и активация другой ячейки, пока в ней не завершено редактирование, падает с ошибкой. Разрывать последовательность между отдельными вызовами инструмента нельзя - режим редактирования строки теряется. Если последовательность всё же разорвана, инструменты **set_cell_text**, **input_text** с **table_name** и **clear_field** сами начинают редактирование строки заново. Колонка таблицы в реальной форме может быть фактически нередактируемой, хотя по данным элемента формы это не видно: **get_form_element_data** показывает обычные 'Вид: Поле ввода', 'Доступность: Да', 'ТолькоПросмотр: Нет'. Это бывает, когда ввод прямо в ячейку формой не предусмотрен (например, вместо ввода открывается отдельный диалог редактирования значения). Старт редактирования по такой колонке завершается ошибкой - это ожидаемая ситуация, а не дефект инструмента: активизируйте действием **activate_column** колонку, которая принимает ввод, и не повторяйте действие с той же колонкой. Для элементов в таблицах используйте параметр **table_name**. Требует подключённого клиента тестирования.

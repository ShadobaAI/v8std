# Vanessa MCP: get_object_attributes

## Контракт и версия

Справочная карточка из `docs/AI/index.md`. Git revision неизвестна; точная редакция определена content_revision и input SHA-256 в manifest.json.
Версия runtime и JSON Schema этим snapshot не подтверждены. Полный контракт конкретного сервера публикуется в `tools/list` и `inputSchema`. Документированное описание ниже может раскрывать отдельные параметры и эффекты, но не устанавливает отсутствующие в нём типы, обязательность, enum или структуру ответа.

## Назначение, документированные параметры и ответ

Получает значения реквизитов объекта (и их тип), связанного с открытой формой. Работает только для форм объектов (Справочники, Документы и т.п.), не работает для форм списков и служебных форм. Параметр **data_mode** определяет состав возвращаемых данных: **all** (все данные - реквизиты шапки и все табличные части), **attributes_only** (только реквизиты шапки), **single_attribute** (значение указанного реквизита, требуется **attribute_name**; если это колонка табличной части - возвращается первая строка этой части, колонки пустой табличной части в этом режиме не находятся), **tabular_sections_only** (только все табличные части), **single_tabular_section** (только указанная табличная часть, требуется **tabular_section_name**). Параметр **only_filled** определяет фильтровать ли пустые реквизиты: true (только заполненные), false (все реквизиты, по умолчанию). В режиме **single_attribute** не применяется: для колонки табличной части в этом режиме первая строка печатается целиком, пустые строки и ссылки - прочерком (—), пустая дата, 0 и Ложь печатаются своим представлением. В режимах с табличными частями true пропускает строки без заполненных значений. В режиме **single_tabular_section** не применяется. Возвращает данные в формате Markdown: реквизиты шапки - строками "Имя (Тип): Значение", табличные части - таблицами с типами колонок в шапке. Данные читаются из активного окна; после чтения инструмент возвращает фокус окну, из которого читал (активизирует его, если активно другое окно).

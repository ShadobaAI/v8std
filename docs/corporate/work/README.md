## Обновление skills

Обратная совместимость удаленных документов и разделов не поддерживается.
У оставшихся шести документов ID `corporate:work:<имя>:overview` не изменились.
Обновите селекторы и проверки количества документов (семь → шесть):

| Старый селектор | Замена |
|---|---|
| `error-reporting` — весь документ и его разделы | `std499`; по механизму также `std783`, `std542`, `std485` |
| `bsl-formatting / Длина строки` и `Параметры` | `std444` |
| `bsl-formatting / Операторы и этапы` | `std456`, пункт 4, и `bsl-formatting / Логические этапы` |
| `module-organization / Клиент-серверное взаимодействие` | `std636` и `std487` |
| `query-conventions / Форматирование` | `std437` |
| `query-conventions / Проверка наличия` | `std438` |
| `query-conventions / Запросы в цикле` | `std436` |
| `query-conventions / Предопределенные значения` | `std443` и `std697` |
| `bsl-type-transparency / Локальные переменные` и `Переменные модуля` | `bsl-type-transparency / Переменные` |

В `bsl-formatting`, `module-organization`, `query-conventions` добавлен раздел
`Общие стандарты`. При выборе темы загружайте применимые нормы по ссылкам,
включая ссылки на диагностики EDT; текст corporate не заменяет эти источники.
Удалите из skills допуски
однострочных запросов и `TODO`/`FIXME`, безусловные требования `Знач`,
внеконтекстного вызова и конструктора: действуют условия и исключения стандартов.

После обновления проверьте селекторы через `scripts/check_work_policy_skills.py`
с `--skills <каталог skills>` и `--pages <свежий pages.jsonl>`.

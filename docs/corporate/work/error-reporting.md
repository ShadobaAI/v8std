# Регистрация и представление ошибок

### Перехват

Соблюдайте [#std499: Перехват исключений в коде](../../std/499.md). Не
используйте исключения для обычного управления ходом выполнения, размещайте
`Попытка` локально и не подавляйте ошибку бесследно.

### Представление и журнал

Если исключение полностью обработано без повторного `ВызватьИсключение`,
поясните причину подавления и запишите подробную информацию в журнал регистрации.
Выбор методов представления ошибки для пользователя и журнала определяется
[#std499](../../std/499.md), без локального переопределения.

### Классификация ошибки

Не определяйте причину ошибки и не ветвите алгоритм по тексту исключения. Для
ветвления используйте структурированные признаки или явную проверку условий.
Сохраняйте исходную информацию об ошибке; прикладное пояснение должно добавлять
контекст операции, а не заменять исходную причину.

### Связанные механизмы

Связанные механизмы дополнительно проверяйте по
[#std783: Транзакции](../../std/783.md),
[#std542: Доступ к файловой системе](../../std/542.md) и
[#std485: Привилегированный режим](../../std/485.md).

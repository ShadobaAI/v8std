# Соглашения для запросов

### Параметры и поля

Передавайте внешние значения через параметры запроса. Выбирайте только
используемые поля.

### Временные таблицы

Имена временных таблиц начинайте с `ВТ_`.

### Установка параметров

Параметры, установка которых не
зависит от условий, устанавливайте сразу после создания объекта `Запрос`.

### Обработка результата

Обрабатывайте результат через выборку, если вызывающему коду не нужна именно
`ТаблицаЗначений`. `Выгрузить()` допустим, когда таблица значений является
необходимым результатом или входом следующей операции.

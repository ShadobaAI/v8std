# Организация модулей и клиент-серверный код

### Области

Создавайте предметную область или подраздел только для нескольких методов
одной темы.

### Экспорт

Добавляйте `Экспорт` только методу, который действительно входит в программный
или служебный программный интерфейс либо вызывается внешним механизмом. Не
экспортируйте внутренние методы на всякий случай.

### Общие стандарты

[#std455](../../std/455.md) — структура модуля;
[#std544](../../std/544.md) и [#std453](../../std/453.md) — экспортный интерфейс;
[#std636](../../std/636.md) и [#std487](../../std/487.md) — клиент-серверное взаимодействие.

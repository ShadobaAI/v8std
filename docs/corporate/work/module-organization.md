# Организация модулей и клиент-серверный код

### Области

Размещайте каждый метод в предметной области по его назначению, а связанные
методы — рядом. Создавайте предметную область или подраздел только для
нескольких методов одной темы. Не создавайте область для каждого метода и не
группируйте методы только по месту исполнения на клиенте или сервере. Общую
структуру модуля задает [#std455](../../std/455.md).

### Экспорт

Добавляйте `Экспорт` только методу, который действительно входит в программный
или служебный программный интерфейс либо вызывается внешним механизмом. Не
экспортируйте внутренние методы на всякий случай. Учитывайте
[#std544](../../std/544.md) и документируйте контракт по
[#std453](../../std/453.md).

### Клиент-серверное взаимодействие

В модуле формы по умолчанию используйте `&НаСервереБезКонтекста`. Применяйте
`&НаСервере`, только когда требуется обращаться к данным формы и передача
контекста оправдана. Не выполняйте серверные вызовы в цикле, если входные данные
можно собрать для одного пакетного вызова. Передавайте между клиентом и сервером
только необходимые данные. См. [#std487](../../std/487.md) и
[#std636](../../std/636.md).
